Learning a Bigram Model with Zero Layers

30 August 2026

A bigram model looks at one token and predicts the next token.

In Why KV Cache and Not QKV Cache?, I used a 0-layer Transformer before adding attention. Here I make that model smaller: one weight table, \(\W\).

We will generate data from known bigram probabilities. Then we will see if nine learned numbers can recover them.

Make the Data

Our vocabulary has three tokens: a, b, and _.

The true transition matrix is

\[ \PB_{\text{true}} = \begin{bmatrix} 0.50 & 0.20 & 0.30 \\ 0.10 & 0.80 & 0.10 \\ 0.90 & 0.05 & 0.05 \end{bmatrix}. \]

A row is the current token. A column is the next token. For example,

\[ P(x_{t+1}=\texttt{b}\mid x_t=\texttt{a})=0.20. \] 
import torch
from torch.utils.data import DataLoader, Dataset
import torch.nn as nn
import torch.nn.functional as F
from torch.optim import AdamW
import matplotlib.pyplot as plt

B = 1_500
T = 1
D = 3

def generate_true_data():
    true_bigrams = {
        "a": torch.tensor([0.50, 0.20, 0.30]),
        "b": torch.tensor([0.10, 0.80, 0.10]),
        "_": torch.tensor([0.90, 0.05, 0.05]),
    }
    vocab = list(true_bigrams.keys())
    n_seq = 100_000

    full_seq = "a"
    all_tokens = [vocab.index(full_seq[-1])]

    for _ in range(n_seq):
        last_token = full_seq[-1]
        sample_arg = torch.multinomial(
            input=true_bigrams[last_token],
            num_samples=1,
        )
        sample_id = sample_arg.item()
        all_tokens.append(sample_id)
        full_seq += vocab[sample_id]

    return full_seq, torch.tensor(all_tokens)

This makes one long string and 100,000 transitions.

Make the Pairs

I will keep the sequence dimension. For this bigram model, \(T=1\). The input is one token. The target is the token after it.

\[ \X,\Y \in \{0,1,2\}^{B \times T}, \qquad B=1500,\quad T=1. \] 
class BigramSequence(Dataset):
    def __init__(self):
        full_seq, all_tokens = generate_true_data()
        self.n_samples = len(all_tokens) - T

        self.X = torch.stack([
            all_tokens[i : i + T]
            for i in range(self.n_samples)
        ])
        self.Y = torch.stack([
            all_tokens[i + 1 : i + T + 1]
            for i in range(self.n_samples)
        ])

    def __getitem__(self, index):
        return self.X[index], self.Y[index]

    def __len__(self):
        return self.n_samples

Before batching, both tensors have shape \(N \times T\). The data loader changes the first dimension from \(N\) to \(B\).

Zero Layers

The complete model is one embedding table:

class ZeroLayer(nn.Module):
    def __init__(self):
        super().__init__()
        self.W = nn.Embedding(
            num_embeddings=D,
            embedding_dim=D,
        )

    def forward(self, x):
        return self.W(x)

nn.Embedding keeps the \(B\) and \(T\) dimensions. It adds one dimension of size \(D\):

\[ \X \in \{0,1,2\}^{B \times T} \quad \xrightarrow{\W} \quad \Z \in \mathbb{R}^{B \times T \times D}. \]

For batch item \(m\) and position \(t\),

\[ \Z_{m,t,:}=\W_{\X_{m,t},:}, \qquad \hat{\Y}_{m,t,:}=\textsf{softmax}(\Z_{m,t,:}). \]

Here \(T=1\). If \(T\) is larger, the same lookup runs at every position. There is still no attention, so the positions do not mix.

Train

One pass over the data is enough for this example.

model = ZeroLayer()
data = BigramSequence()
loader = DataLoader(data, batch_size=B)
optimizer = AdamW(model.parameters(), lr=0.1)

losses = []

for x, y in loader:
    optimizer.zero_grad()

    logits = model(x)                 # [B, T, D]
    loss = F.cross_entropy(
        logits.transpose(1, 2),       # [B, D, T]
        y,                            # [B, T]
    )

    loss.backward()
    optimizer.step()
    losses.append(loss.item())

Cross entropy applies softmax internally. So the model returns raw logits during training. PyTorch expects the class dimension second:

\[ B \times T \times D \quad \xrightarrow{\textsf{transpose}(1,2)} \quad B \times D \times T. \]

Read the Weights

Apply softmax to each row of \(\W\):

with torch.no_grad():
    learned_bigrams = model.W.weight.softmax(dim=1)
    print(learned_bigrams)

plt.plot(losses)
plt.xlabel("update")
plt.ylabel("cross entropy")
plt.show()
